# python-data-structures
# Python Data Structures & Practice Exercises

This repository holds my Jupyter Notebook practice assignments where I explore core Python data structures, standard methods, and conditional logic.

## Overview of Notebooks

### 1. Strings & Tuples
* Working with string operations and methods.
* Practicing tuple creation, indexing, and immutability concepts.

### 2. Lists, Dictionaries, Sets & Conditionals
* **Lists**: Creating, updating (`append`, `insert`, `pop`, `extend`), sorting, and slicing elements.
* **Dictionaries**: Key-value mapping, modifying student records, and using `.keys()`, `.values()`, and `.items()` methods.
* **Sets**: Observing automatic duplicate removal, testing set immutability, and computing `union` and `intersection`.
* **Control Flow**: Building a score evaluator with interactive user inputs using `if-elif-else` conditions.

## How to Run
1. Clone this repository or download the `.ipynb` files.
2. Open them in **Jupyter Notebook** or **JupyterLab**.
3. Run the cells sequentially to see the outputs and interactive prompts.

## Tools
* Python 3
* Jupyter Notebook
